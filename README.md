# Dream Cafe Polish

Dream Cafe — Professional Restaurant Website Design Prompt

Create a premium, modern, warm, image-driven multi-page restaurant website for Dream Cafe, a popular cafe/restaurant located in Mirpur-1, Dhaka, Bangladesh.

This must NOT look like a generic AI-generated restaurant template. The website should feel like a real, established local cafe with its own personality, atmosphere, food, and visual identity.

Business Name: Dream Cafe

Facebook: https://www.facebook.com/DreamCafeMirpur/

Business Type: Cafe / Restaurant / Fast Food / Pizza / Thai Restaurant

Opening Hours: 11:00 AM – 11:00 PM, every day

CORE DESIGN DIRECTION

Design the website with a light, elegant, warm cafe aesthetic.

Do NOT use a dark luxury restaurant theme.

The overall visual feeling should be:

Warm

Clean

Premium

Friendly

Modern

Comfortable

Food-focused

Instagram-worthy

Local but professionally designed

Use a light color palette inspired by a real cafe environment:

Warm ivory / cream background

Soft white sections

Light beige

Warm coffee/brown accents

Subtle muted green or earthy accent where appropriate

Dark charcoal typography for readability

Avoid excessive gradients.

Avoid neon colors.

Avoid overly saturated colors.

Avoid making the website look like a SaaS website.

Use generous whitespace, elegant typography, rounded image containers, subtle shadows, thin borders, and tasteful micro-interactions.
